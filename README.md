# NPP Hải Hà – Điều hành

- `/` – Web "Hải Hà – Điều hành" cho toàn NPP (doanh số, giao hàng, chưa giao, công nợ, tồn kho, tải trọng Pepsi, lương giao hàng, thi đua Tết). Dữ liệu mã hóa theo mật khẩu từng tài khoản; mỗi tài khoản chỉ tải gói dữ liệu của mình trong thư mục `d/`.
- `/vinamilk/` – Trang "Theo dõi bán hàng Hải Hà" (Vinamilk), tài khoản riêng.

Lưu ý khi cập nhật trang Vinamilk: ghi vào `vinamilk/index.html` và `vinamilk/keys.json`, không ghi đè `index.html` ở thư mục gốc.
